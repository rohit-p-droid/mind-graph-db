# Mind Graph DB - User Manual & Complete Usage Guide

Welcome to **Mind Graph DB**, a hybrid **semantic + vector + graph database** built natively in Python.

Mind Graph DB stores unstructured text documents, automatically generates dense vector embeddings, extracts named entities, concepts, and factual triples using open-source pretrained NLP models, discovers cross-document relationships using vector similarity candidate search, maintains a persistent semantic knowledge graph with evidence provenance, and allows querying via a custom domain query language, a Python Client SDK, or a FastAPI REST Web Service.

## 1. Quick Start & Installation

### Environment Setup

Ensure Python 3.10+ is installed. Activate your virtual environment and install dependencies:

```bash
# Navigate to project directory
cd mind-graph-db

# Activate virtual environment (Windows)
.venv\Scripts\activate

# Install package in editable mode
pip install -e .
```

Try running the built-in runnable demonstration script:

```bash

```

This script automatically ingests documents, generates vector embeddings, builds the knowledge graph, displays an ASCII visualization, updates document content (pruning stale edges and creating new links), and executes a domain query with evidence provenance.

## 2. Core Architecture & Concepts

- **Documents**: Unstructured text content with auto-generated UUIDs, created/updated timestamps, and metadata dictionary payloads.
- **Vectors**: Dense numerical embeddings generated by sentence transformer models or hashing models, stored separately from raw document text for exact cosine similarity candidate discovery.
- **Entities & Facts**: Extracted Named Entities (`PERSON`, `ORG`, `TECHNOLOGY`, `CONCEPT`) and Subject-Verb-Object (SVO) factual triples extracted via spaCy or rule-based NLP engines.
- **Graph Nodes & Directed Edges**: Custom `SQLiteGraphStore` storing `DOCUMENT` and `ENTITY` nodes connected by typed `Relationship` edges (`MENTIONS`, `SIMILAR_TO`, `USES_STORAGE`).
- **Confidence Scores & Evidence Provenance**: Every edge stores a confidence score $[0.0, 1.0]$ and an explicit `evidence_text` string explaining why the link was established.

## 3. Method 1: Using the Python Client SDK

The **`MindGraphDBClient`** SDK supports two execution modes:
1. **Remote HTTP Mode**: Connects over HTTP REST API to a running FastAPI server.
2. **In-Process Mode**: Operates embedded directly inside your Python process without needing an external web server.

### SDK Code Example

```python
from mind_graph_db.sdk import MindGraphDBClient

# Option A: In-Process Mode (embedded local storage)
client = MindGraphDBClient(db_dir="./storage")

# Option B: Remote HTTP Mode (connect to FastAPI server)
# client = MindGraphDBClient(base_url="http://localhost:8000")

# 1. Create and ingest document
result = client.create_document(
    text="Mind Graph DB is an open source hybrid vector database built in Python.",
    metadata={"category": "database", "author": "Alice"},
)
print(f"Ingested Doc ID: {result.document_id} | Entities Extracted: {result.entities_extracted}")

# 2. Retrieve document
doc = client.get_document(result.document_id)
print("Retrieved Text:", doc.text)

# 3. Perform semantic similarity search
search_results = client.semantic_search("Python vector database", top_k=5)
for item in search_results:
    print(f"Found Doc: {item['document_id']} | Score: {item['score']:.3f}")

# 4. Submit custom domain query statement
query_res = client.query(
    'FIND documents '
    'WHERE semantic_match("Python database") AND metadata.category = "database" '
    'TRAVERSE 2 HOPS '
    'RETURN documents, entities, relationships'
)
print("Query Documents:", [d.id for d in query_res.documents])

# 5. Update document content (automatically prunes stale edges)
update_res = client.update_document(
    document_id=result.document_id,
    text="Mind Graph DB is an open source hybrid database integrating Python and SQLite.",
    metadata={"version": 2},
)
print(f"Updated Doc | Edges Removed: {update_res.relationships_removed}")

# 6. Multi-hop Graph Traversal
paths = client.traverse(start_node_id=result.document_id, max_hops=2)
for path in paths:
    print(f"Hop Depth {path.hop_count}: {[n.label for n in path.nodes]}")

# 7. Delete document
client.delete_document(result.document_id)

client.close()
```

## 4. Method 2: Using the FastAPI REST Web Service

### Starting the Server

Launch the web service using `uvicorn`:

```bash
uvicorn mind_graph_db.api.app:create_app --factory --host 127.0.0.1 --port 8000 --reload
```

Interactive OpenAPI documentation is available in your browser at `http://127.0.0.1:8000/docs`.

### REST Endpoint Reference & cURL Examples

#### 1. Ingest Document (`POST /api/v1/documents`)
```bash
curl -X POST "http://127.0.0.1:8000/api/v1/documents" \
  -H "Content-Type: application/json" \
  -d '{"text": "Python is used by Google for backend services.", "metadata": {"category": "tech"}}'
```

#### 2. Get Document (`GET /api/v1/documents/{id}`)
```bash
curl -X GET "http://127.0.0.1:8000/api/v1/documents/<doc_id>"
```

#### 3. Semantic Similarity Search (`POST /api/v1/search`)
```bash
curl -X POST "http://127.0.0.1:8000/api/v1/search" \
  -H "Content-Type: application/json" \
  -d '{"query": "Python Google AI", "top_k": 5}'
```

#### 4. Domain Query (`POST /api/v1/query`)
```bash
curl -X POST "http://127.0.0.1:8000/api/v1/query" \
  -H "Content-Type: application/json" \
  -d '{"query": "FIND documents WHERE semantic_match(\"Python\") TRAVERSE 2 HOPS", "top_k": 5}'
```

#### 5. Graph Traversal (`POST /api/v1/graph/traverse`)
```bash
curl -X POST "http://127.0.0.1:8000/api/v1/graph/traverse" \
  -H "Content-Type: application/json" \
  -d '{"start_node_id": "<doc_id>", "max_hops": 2}'
```

## 5. Method 3: Direct Core Python API

For lower-level control, instantiate component services directly:

```python
from mind_graph_db.core.types import Document
from mind_graph_db.embeddings import HashEmbeddingModel
from mind_graph_db.nlp import RuleBasedNLPModel
from mind_graph_db.pipeline import DocumentIngestionPipeline
from mind_graph_db.query import MindQueryEngine
from mind_graph_db.storage import SQLiteDocumentStore, SQLiteGraphStore, SQLiteVectorStore

# Initialize components
doc_store = SQLiteDocumentStore(db_path="./storage/documents.db")
vec_store = SQLiteVectorStore(db_path="./storage/vectors.db")
graph_store = SQLiteGraphStore(db_path="./storage/graph.db")
embedding_model = HashEmbeddingModel(dim=128)
nlp_model = RuleBasedNLPModel()

# Instantiate Pipeline & Query Engine
pipeline = DocumentIngestionPipeline(
    document_store=doc_store,
    vector_store=vec_store,
    graph_store=graph_store,
    embedding_model=embedding_model,
    nlp_model=nlp_model,
    min_confidence=0.5,
)
query_engine = MindQueryEngine(
    document_store=doc_store,
    vector_store=vec_store,
    graph_store=graph_store,
    embedding_model=embedding_model,
)

# Ingest document
doc = Document(text="Mind Graph DB connects vectors and semantic graphs.")
pipeline.ingest_document(doc)

# Query
result = query_engine.query('FIND documents WHERE semantic_match("graph") TRAVERSE 1 HOPS')
print("Documents Found:", len(result.documents))

doc_store.close()
vec_store.close()
graph_store.close()
```

## 6. Domain Query Language Guide

Mind Graph DB includes a custom query language combining vector semantic search, metadata filtering, and graph traversal:

### Syntax Template
```sql
FIND <target>
WHERE semantic_match("<query_string>") AND metadata.<key> = "<value>"
TRAVERSE <hops> HOPS WITH RELATIONSHIPS ["<rel_type_1>", "<rel_type_2>"]
RETURN documents, entities, relationships
```

### Examples

1. **Basic Semantic Vector Search**:
   ```sql
   FIND documents WHERE semantic_match("Tesla battery production")
   ```

2. **Combined Semantic Match + Metadata Filter**:
   ```sql
   FIND documents WHERE semantic_match("artificial intelligence") AND metadata.category = "tech"
   ```

3. **Multi-Hop Traversal with Relationship Type Filtering**:
   ```sql
   FIND documents WHERE semantic_match("Python database") TRAVERSE 2 HOPS WITH RELATIONSHIPS ["MENTIONS", "SIMILAR_TO"] RETURN documents, entities, relationships
   ```

## 7. Document Updates & Stale Edge Cleanup

When a document's content is modified (`update_document`), Mind Graph DB automatically reconciles the graph:
1. **Timestamping**: Updates `updated_at` timestamp.
2. **Re-embedding**: Overwrites dense vector in `VectorStore`.
3. **Re-indexing & Entity Resolution**: Extracts new entities and preserves existing canonical entity nodes.
4. **Stale Edge Pruning**: Automatically deletes graph relationships connected to removed entities or concepts.
5. **Valid Relationship Preservation**: Keeps still-valid edges, updating confidence scores and `evidence_text` provenance.

## 8. Graph Visualizer & Debugging Utility

Mind Graph DB provides both interactive web-based visual graph explorers and CLI ASCII debugging utilities:

### 1. Interactive Browser Visualizer (`client.visualize()`)
In your Python script, call `client.visualize()` to automatically generate an interactive HTML visual graph application and launch it in your browser:

```python
from mind_graph_db.sdk import MindGraphDBClient

client = MindGraphDBClient(db_dir="./storage")
# Generate graph.html and open in default web browser
client.visualize(output_html_path="graph.html", auto_open=True)
```

### 2. FastAPI Web UI Dashboard (`/visualize`)
When running the FastAPI server (`uvicorn mind_graph_db.api.app:create_app --factory`), visit:
**`http://localhost:8000/visualize`**

### 3. CLI & Programmatic Exporters (`GraphVisualizer`)

```python
from mind_graph_db.utils import GraphVisualizer

# Print ASCII Tree Representation in CLI
print(GraphVisualizer.render_ascii(graph_store, max_depth=2))

# Export Standalone Interactive HTML File
GraphVisualizer.export_html(graph_store, output_path="my_graph.html")

# Export Graph JSON / Graphviz DOT
json_data = GraphVisualizer.export_json(graph_store)
dot_syntax = GraphVisualizer.export_dot(graph_store)
```
